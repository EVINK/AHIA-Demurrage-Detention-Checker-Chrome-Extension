连接与默认选项
推荐使用 Gmail 网页。用电脑上的邮件程序时：
  • 插件打开填好收件人、抄送、主题和正文的写信窗口，不能自动发送，需要你在邮件程序里点发送。
  • 插件无法确认是否已发出，发完后要回到插件点「我已发送」，记录才会变成已发送。
  • 签名由邮件程序自己添加，插件不检查签名。
  • 第一次使用时 Chrome 会询问是否打开外部程序，请勾选「始终允许」；Windows 的默认邮件程序需要先设置好。

插件只能打开 Windows 默认邮件程序（无法直接指定其他程序，也无法检测是否已安装），这里选的程序必须与 Windows 默认邮件程序一致。没有安装：下载 Foxmail · 下载 Outlook（Microsoft Store） · 打开 Windows 默认应用设置（搜索「MAILTO」并选择）。

实验性功能：Gmail 自动抄送（Auto CC）

开启后，在 Gmail 里写信或回复时，发件人是下面列出的邮箱才自动加上抄送；其他发件人不做任何改动，也不提示。开启后 Gmail logo 右侧会出现「Auto CC」按钮，点击回到这里。
